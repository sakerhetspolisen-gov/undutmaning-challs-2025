# Beskrivning

Astronauten **Clive Sinclair** vill skicka ett meddelande till **Ken Olsen** i rymdstationen tvärs över gatan.
De har ingen radiokontakt så han spelar in meddelandet på ett kassettband och skjuter det genom rymden med slangbella. 
Av artighetsskäl kodar han meddelandet på ett sätt som han vet att Ken förstår.

Ken känner sig dock förvirrad och behöver hjälp. Kan du hjälpa honom plocka fram texten i meddelandet?
Resultatet borde bli en kort rad med läsbar text. Ange hela den strängen som flagga, inklusive mellanslag och punkt.

Lycka till!

* Hint: steg1: Den mest populära datorn från Clive Sinclair
* Hint: steg2: Teckenkodning som användes i Ken Olsens mest populära system

# För granskare

- Lösning beskrivs i `./solution`. Saknar automatiskt skript för att text måste flyttas ut från en emulator.
- Kräver Googling/ChatGPT för att följa hints från beskrivningen. Om man inte är bekant med Clive Sinclair eller Ken Olsen.
