# Beskrivning

På en oskyddad fileshare har Harriet hittat vad som verkar vara någon form av krypterat meddelande.
Det verkar faktiskt som om Kenneth har använt sig av Mixed Boolean Arithmetic (MBA) för att kryptera det.
Vad Harriet vet så är MBA väldigt användbart för till exempel kodobfuskering, men kan det vara så att det kan utgöra ett utmärkt krypto också?

Ta reda på om Kenneth har klantat till det!

hint: Slösa inte bort någon tid på att försöka deobfuskera den här röran. Ekvationerna är slumpmässigt genererade.
